# โครงสร้างข้อมูลกฎหมาย (Law Data Schema)

ทุกไฟล์ใน `data/` เป็น JSON (UTF-8) ที่เว็บอ่านไปทำ dropdown และเติมข้อความในคำฟ้องอัตโนมัติ
ข้อความทั้งหมดเป็นภาษาไทย ใช้เลขอารบิกในฟิลด์ `section` (ระบบแปลงเป็นเลขไทยตอนออกเอกสารเอง)

## 1) ไฟล์ความผิดอาญา / มูลคดีแพ่ง (`criminal-code.json`, `criminal-special.json`, `civil-code.json`)

โครงไฟล์: `{ "law": {...}, "items": [ ... ] }`

```jsonc
{
  "law": {
    "id": "pc",                         // รหัสสั้น a-z ไม่ซ้ำกันทั้งระบบ
    "name": "ประมวลกฎหมายอาญา",
    "short": "ป.อ.",                    // ชื่อย่อที่ใช้อ้างในคำฟ้อง
    "note": "ฉบับปรับปรุงล่าสุดที่ตรวจสอบ ..."
  },
  "items": [
    {
      "id": "pc-288",                   // {law.id}-{section}[-{sub}] ไม่ซ้ำ
      "section": "288",                 // มาตรา (string) เช่น "83", "341", "4(2)" 
      "name": "ฆ่าผู้อื่น",              // ชื่อฐานความผิด/มูลคดี สั้น ๆ ที่ผู้ใช้เห็นใน dropdown
      "category": "ความผิดเกี่ยวกับชีวิตและร่างกาย", // กลุ่มสำหรับ optgroup
      "kind": "criminal",               // "criminal" | "civil"
      "text": "ผู้ใดฆ่าผู้อื่น ...",     // ตัวบทหรือสรุปองค์ประกอบความผิดโดยย่อ (ไม่ต้องคัดทั้งมาตราถ้ายาว)
      "elements": ["ผู้ใด", "ฆ่า", "ผู้อื่น", "โดยเจตนา"], // องค์ประกอบความผิด (ใช้เตือนผู้ใช้ว่าข้อเท็จจริงต้องครบ)
      "penalty": "ประหารชีวิต หรือจำคุกตลอดชีวิต หรือจำคุก 15 ถึง 20 ปี", // ระวางโทษ (สำหรับ criminal)
      "privateOffence": false,          // true = ความผิดต่อส่วนตัว (ต้องร้องทุกข์/ฟ้องภายใน 3 เดือน ป.อ. ม.96) — criminal เท่านั้น
      "compoundable": false,            // true = ยอมความได้ (ป.วิ.อ. ม.39(2)) 
      "limitation": "ไม่มีอายุความตามมาตรา 95 ... / 20 ปี",  // อายุความ
      "relatedSections": [              // มาตราที่มักอ้างประกอบ (รวมมาตราเพิ่มโทษ/ริบ/ช่วยเหลือ/พยายาม/ตัวการ)
        { "ref": "ป.อ. มาตรา 80", "why": "พยายามกระทำความผิด" },
        { "ref": "ป.อ. มาตรา 83", "why": "ตัวการร่วมกระทำผิด" }
      ],
      "factTemplate": [                 // ร่างข้อความ "ข้อ ๑, ข้อ ๒ ..." ในคำฟ้อง (อย่างน้อย 2 ข้อ)
        "เมื่อวันที่ {{วันเวลาเกิดเหตุ}} เวลากลางวัน ต่อเนื่องกัน จำเลยได้บังอาจ ... {{สถานที่เกิดเหตุ}} ..."
      ],
      "prayerTemplate": [               // ร่างคำขอท้ายฟ้อง (ข้อความที่ต่อจาก "ขอให้ลงโทษ...") อย่างน้อย 1 ข้อ
        "ขอให้ลงโทษจำเลยตามกฎหมาย"
      ],
      "civilClaim": {                   // ถ้าความผิดนี้มักมีคำขอทางแพ่งแนบ (ป.วิ.อ. ม.43, 44/1) ใส่ได้ ไม่มีให้ละไว้
        "available": true,
        "note": "ขอให้จำเลยคืนทรัพย์หรือใช้ราคา ตาม ป.วิ.อ. มาตรา 43 / ค่าสินไหมทดแทน ม.44/1"
      },
      "caution": "ข้อควรระวัง/จุดที่ศาลมักยกฟ้อง/ต้องมีองค์ประกอบภายใน (ถ้ามี) — ไม่เกิน 2 ประโยค",
      "source": "https://www.krisdika.go.th/... หรือ ชื่อกฎหมาย ฉบับที่/พ.ศ. ที่ใช้ตรวจ", // บังคับ: บอกแหล่งที่ตรวจ
      "verified": true                  // true = ตรวจเลขมาตรา/ตัวบท/โทษกับแหล่งอ้างอิงแล้ว false = เขียนจากความรู้ ยังไม่ได้ตรวจ
    }
  ]
}
```

### ตัวแปรใน `factTemplate` / `prayerTemplate`
- `{{ชื่อ}}` = ช่องที่ผู้ใช้ต้องกรอกในหน้าเว็บ ใช้ชื่อภาษาไทยสั้น ๆ เช่น `{{วันเวลาเกิดเหตุ}}` `{{สถานที่เกิดเหตุ}}` `{{ทรัพย์สิน}}` `{{มูลค่า}}` `{{ผู้เสียหาย}}`
- ตัวแปรสงวน (ระบบเติมเองจากข้อมูลคู่ความ): `{{โจทก์}}` `{{จำเลย}}` `{{ศาล}}` `{{มาตรา}}`
- ห้ามใส่ข้อเท็จจริงจริงของบุคคลใดในเทมเพลต
- เขียนภาษาคำฟ้องแบบมืออาชีพ: “เมื่อวันที่ ... เวลากลางวัน/กลางคืน ... จำเลยได้บังอาจ ... เหตุเกิดที่ ... ตำบล... อำเภอ... จังหวัด... ซึ่งเป็นความผิดตามประมวลกฎหมายอาญา มาตรา ...”

## 2) ไฟล์วิธีพิจารณา (`procedure.json`)

```jsonc
{
  "laws": [ { "id": "pvor", "name": "ประมวลกฎหมายวิธีพิจารณาความอาญา", "short": "ป.วิ.อ." }, ... ],
  "sections": [
    {
      "id": "pvor-162",
      "law": "pvor",
      "section": "162",
      "title": "ไต่สวนมูลฟ้อง",
      "summary": "สรุปสาระ 1–3 ประโยค",
      "usedIn": ["complaint-criminal", "motion"],   // เอกสารที่มักอ้าง (ดู docTypes ด้านล่าง)
      "source": "...", "verified": true
    }
  ],
  "snippets": [      // ข้อความสำเร็จรูปที่ใช้ซ้ำในคำร้อง/คำฟ้อง (ผู้ใช้เลือก checkbox ใส่เอกสาร)
    {
      "id": "serve-by-posting",
      "docType": "motion",                 // complaint-criminal | complaint-civil | prayer-criminal | prayer-civil | motion | witness-list | power-of-attorney ...
      "title": "ขอส่งหมายโดยปิดหมาย",
      "text": "หากเจ้าพนักงานเดินหมายไปส่งแล้วไม่พบ {{จำเลย}} หรือไม่มีผู้ใดยอมรับไว้แทน โจทก์ขอให้ศาลอนุญาตให้ส่งโดยวิธีปิดหมาย ณ ภูมิลำเนาของ {{จำเลย}} ตามประมวลกฎหมายวิธีพิจารณาความแพ่ง มาตรา 79 ประกอบประมวลกฎหมายวิธีพิจารณาความอาญา มาตรา 15 ...",
      "refs": ["ป.วิ.พ. มาตรา 79", "ป.วิ.อ. มาตรา 15"],
      "source": "...", "verified": true
    }
  ]
}
```

## 3) ศาลและที่อยู่ (`courts.json`, `geo.json`)
กำหนดในงานของ agent ที่เกี่ยวข้อง (ดูคำสั่งงาน)

## กติการ่วม
- เลขมาตราต้องถูกต้อง ถ้าไม่แน่ใจ ให้ตั้ง `"verified": false` อย่าเดา และอธิบายใน `caution`
- ห้ามแต่งเลขฎีกา/คำพิพากษา
- ใช้ UTF-8 ไม่ใส่ BOM, JSON ต้อง parse ได้ (ตรวจด้วย `node -e "JSON.parse(require('fs').readFileSync(f,'utf8'))"`)
