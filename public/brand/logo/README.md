## สี

- **ส้ม (สีหลัก)** `#f26b1d` · ส้มเข้ม `#c2410c` (ตัวหนังสือรอง/ปุ่มกด) · ส้มอ่อน `#fff1e8` (พื้นป้าย) · ครีม `#ffe9da` (ตัวหนังสือรองบนพื้นส้ม)
- ดำ `#1d1d1f` (ชื่อบนพื้นสว่าง) · ขาว `#ffffff` · เทารอง `#4b5563`
- เว็บไซต์และหลังบ้านใช้ส้มชุดเดียวกันเป็นสีปุ่ม/ลิงก์/จุดเน้น (ตัวแปร `--blue` ใน CSS ถูกตั้งเป็นส้มแล้ว — ชื่อตัวแปรคงไว้เพราะไฟล์อื่นอ้างอิง) ไล่สีหัวเรื่อง `#ff8a3d → #f2541d → #c81d4f` · ภาพตัวอย่างลิงก์ (og-image.png / og-pdf.png) และ favicon ใช้พื้นส้มเดียวกัน

## ตัวอักษร

- ชื่อ `LawCraft` หนา 700, `by PKT (เพ็ช ไพศาณ)` น้ำหนัก 500, บรรทัดไทยน้ำหนัก 500 — ฟอนต์ **Noto Sans Thai** (ฟรี, Google Fonts)
- ไฟล์ SVG อ้างอิงฟอนต์ตามชื่อ (ไม่ได้ฝังฟอนต์) เครื่องที่ไม่มี Noto Sans Thai จะแสดงด้วยฟอนต์สำรอง → งานพิมพ์ให้ใช้ไฟล์ PNG ซึ่ง render ด้วยฟอนต์ที่ถูกต้องแล้ว หรือติดตั้ง Noto Sans Thai ก่อนเปิด SVG

## สร้างใหม่

ชุดนี้สร้างด้วยสคริปต์ (SVG ประกอบจากเส้นตราชั่งเดียวกับไอคอนของเว็บ แล้ว render PNG ด้วย Edge headless) — แก้ข้อความ/สีแล้วรันใหม่ได้ทั้งชุด
