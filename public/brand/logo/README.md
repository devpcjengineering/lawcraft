# โลโก้ LawCraft by PKT (ลอว์คราฟต์ โดยสำนักงานกฎหมาย PKT)

ไฟล์ทั้งหมดอยู่ในโฟลเดอร์นี้ (`/brand/logo/` บนเว็บ) — SVG เป็นไฟล์ต้นฉบับ (ขยายได้ไม่แตก) ส่วน PNG พื้นหลังโปร่งใส render ไว้หลายขนาด (ตัวเลขท้ายชื่อ = ความกว้างเป็นพิกเซล)

| แบบ | ไฟล์ | ใช้กับ |
|---|---|---|
| เครื่องหมาย (ตราชั่ง) อย่างเดียว | `lawcraft-mark.svg` (ดำ) · `-navy` · `-white` · `-gold` + PNG 256/1024 | ไอคอนเล็ก ลายน้ำ ตราประทับ |
| วงกลม | `lawcraft-circle-navy.svg` (พื้นกรมท่า) · `-gold` · `-white` · `-black` + PNG 512/1024 | รูปโปรไฟล์ LINE / Facebook / Google Business |
| สี่เหลี่ยมมุมมน | `lawcraft-square-navy.svg` · `-black` · `-white` + PNG 512/1024 | ไอคอนแอป / favicon ขนาดใหญ่ |
| แนวนอน (เครื่องหมาย + ชื่อ + บรรทัดไทย) | `lawcraft-logo-horizontal.svg` (ดำ) · `-navy` · `-white` (ใช้บนพื้นเข้ม) · `-on-navy` (มีพื้นกรมท่า) · `-tagline` (บรรทัดล่างเป็นสโลแกน) + PNG 1280/2560 | หัวเว็บ หัวจดหมาย นามบัตร ป้าย |

| ตัวอักษรอย่างเดียว | `lawcraft-wordmark.svg` · `-white` + PNG 1040/2080 | ท้ายจดหมาย ลายเซ็นอีเมล |

## สี

- กรมท่า (หลัก) `#0b1f45` · ทอง (เน้น) `#e8c56a` · ดำ `#1d1d1f` · ขาว `#ffffff` · เทารอง `#4b5563` (บนพื้นสว่าง) / `#cfdaf0` (บนพื้นเข้ม)

## ตัวอักษร

- ชื่อ `LawCraft` หนา 700, `by PKT` น้ำหนัก 500, บรรทัดไทยน้ำหนัก 500 — ฟอนต์ **Noto Sans Thai** (ฟรี, Google Fonts)
- ไฟล์ SVG อ้างอิงฟอนต์ตามชื่อ (ไม่ได้ฝังฟอนต์) เครื่องที่ไม่มี Noto Sans Thai จะแสดงด้วยฟอนต์สำรอง → งานพิมพ์ให้ใช้ไฟล์ PNG ซึ่ง render ด้วยฟอนต์ที่ถูกต้องแล้ว หรือติดตั้ง Noto Sans Thai ก่อนเปิด SVG

## สร้างใหม่

ชุดนี้สร้างด้วยสคริปต์ (SVG ประกอบจากเส้นตราชั่งเดียวกับไอคอนของเว็บ แล้ว render PNG ด้วย Edge headless) — แก้ข้อความ/สีแล้วรันใหม่ได้ทั้งชุด
